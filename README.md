# 🛒 Shoply

A modern and responsive e-commerce storefront built with vanilla HTML, CSS and JavaScript.

Shoply provides a clean shopping experience with product search, category filtering, shopping cart management and theme switching.

## ✨ Features

- 🛍️ Product catalog
- 🔎 Product search
- 🏷️ Category filtering
- 🛒 Shopping cart
- ➕ Add and remove products
- 🔢 Increase/decrease product quantity
- 💰 Automatic cart total calculation
- 💾 Cart persistence with LocalStorage
- 🌙 Dark / light mode
- 📱 Responsive design
- 🔔 Interactive notifications
- ⚡ No frameworks or external dependencies

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- DOM API
- LocalStorage
